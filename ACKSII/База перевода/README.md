# База перевода ACKS II Revised Rulebook

Английский текст всей книги извлечён и разбит на единицы перевода. На 16 октября 2026 года русский текст заполнен и сверён до конца пятой главы: физические страницы PDF 1–263, включая начало книги и главы 1–5. Всего переведено 15 783 единицы; глава 5 «Заклинания» — 2 861 из 2 861. Глава 6 и далее имеют статус `pending`.

Файл для чтения — `../Перевод Markdown/ACKS II — Начало и главы 1–5.md`, продолжение прежнего файла глав 1–2. Компактный документ сохраняет введение, оглавление, правила, 175 таблиц и 434 редакторских примечания. Маркеры PDF 5–263 стоят мелко справа и ведут к оригиналу; страницы разделены горизонтальными линиями. Под русскими заголовками сохранены меньшие английские строки. При добавлении главы 5 текст прежнего диапазона PDF 5–179 сохранён без изменений.

Полные отдельные файлы `00 Начало.md`, `01 Персонажи.md`, `02 Классы.md` и `03 Навыки.md` сохраняют весь диапазон PDF 1–123 и идентификаторы единиц. Исправления и комментарии со звёздочками находятся рядом с соответствующим текстом. Проверка новой главы — [03_review.md](03_review.md) и [03_validation.json](03_validation.json); текущая проверка компактного общего файла — [reading_validation.json](reading_validation.json). Более ранние отчёты относятся к своим историческим диапазонам.

Компактная копия собирается из полных отдельных Markdown-файлов скриптом `../../.work/reading-md/format_reading.py`. После повторной полной сборки его нужно запускать последним. Скрипт проверяет сохранность текста правил, всех таблиц, английских подзаголовков и всех комментариев. Примечание с обложки о расхождении в числе классов перенесено к началу описания классов на PDF-странице 25.

По уточнению пользователя специальные и неоднозначные термины сопровождаются английским именем в квадратных скобках при каждом употреблении, а под русскими заголовками дана отдельная английская строка. Правила продолжения этого оформления — [bilingual_style.md](bilingual_style.md); текущая карта подписей — [bilingual_terms.md](bilingual_terms.md). Основной глоссарий и проверенный русский текст в базе при этом не переписывались.

## Файлы

- `acksii_translation.sqlite` — основная база: английский текст, русский перевод, таблицы, страницы, словарь, исходные черновики и история изменений.
- `units.jsonl` — полная выгрузка английских и русских единиц; одна JSON-запись на строку. У ещё не переведённых единиц поле `russian` равно `null`.
- `front_matter_review.csv` и `01_review.csv` — двуязычные таблицы для чтения и редактирования в Excel. Кодировка UTF-8 с BOM, разделитель `;`. При импорте в Excel задавайте текстовый тип столбцов, чтобы формулы, номера и обозначения костей сохранялись буквально.
- `03_review.csv` — свежая выгрузка главы 3 с `revision: 1`. Пакеты `../../contributions/03/translator.csv` и `.jsonl` сохраняют исходную `revision: 0`, с которой выполнен импорт. Для дальнейших правок выгружайте актуальные редакции; повторный импорт старого пакета вызовет конфликт.
- `glossary.json` — словарь из ReadMe с исходными формулировками, вариантами, сокращениями и происхождением.
- `progress.json` — состояние глав в этой базе. Исходная книга «Прогресс перевода.xlsx» не изменена.
- `review.md` — сводка текущей проверки и прежних этапов; `02_review.md` и `03_review.md` — подробные проверки соответствующих глав.
- `validation.json`, `02_validation.json`, `03_validation.json`, `workflow_validation.json` — результаты проверок базы, Markdown и процесса обновления с указанием диапазона и даты.
- `schema.sql`, `database_tools.py` — структура базы и переносимые средства работы; достаточно стандартного Python с SQLite/FTS5.

## Единицы и страницы

Абзацы, заголовки, пункты списков и ячейки таблиц имеют постоянные идентификаторы, например `rr.p0015.b003` и `rr.p0019.t01.r002.c02`. Номер после `p` — физическая страница PDF, начиная с 1. `printed_page` хранит печатный номер отдельно; у обложек он отсутствует. Для внутренних ссылок сохранены номера страниц оригинала.

У таблиц сохранены размеры, порядок строк и столбцов, объединения ячеек и английская разметка. Числовые клетки не исключены из базы. Значки урона представлены текстовыми тегами и отдельными метаданными о типе и категории урона. Английский текст можно восстановить из `pages.source_markup`; он также доступен в `../Source/ACKSII Revised Rulebook (EN checked).md`.

Исходные фрагменты Word находятся в `draft_fragments`, связь с редакцией — в `unit_drafts`. Это позволяет видеть полный черновик даже тогда, когда его один абзац был разделён на несколько единиц оригинала. Текущий русский текст находится в `translations`, все его редакции — в `translation_revisions`. Статус `reviewed` означает проверку Codex; он не означает утверждение пользователем.

## Терминология

Словарь для чтения — [Глоссарий.md](../Глоссарий.md); машинная версия — `glossary.json`. В базе сохранены оригинальные записи и редакционные пометы. Отдельно отмечены утверждённые пользователем «Природоведение», «Мифография» и «Особый урон». Падеж, число и регистр слов могут меняться по контексту. Варианты, которых нет в словаре, хранятся отдельно в `working_labels` со статусом `working`; они не являются утверждёнными дополнениями к словарю. Нерешённые пометы перечислены в `issues` и `review.md`.

Категория словаря учитывается по контексту: например, Venturer — «Торговец» как класс, Venturers — «Купцы» в разделе НПС; Spells — «от заклинаний» в списке спасбросков, но «Заклинания» как название главы. `unit_terms` хранит кандидатов на словарное соответствие по совпадению английского текста, а не автоматически подтверждённые термины: омонимы и разные категории требуют смысловой проверки.

## Работа с базой

Текущий перевод до конца главы 5 и общий документ выпущены в Markdown; SQLite и `units.jsonl` синхронизированы с ними. Главы 3–5 импортированы через `database_tools.py import-chapter` после резервного копирования, затем выполнены `verify` и `export`. CSV-таблица главы 2 по-прежнему не создавалась; существующие CSV начала и главы 1 сохранены. Статус `reviewed_by_Codex` не означает утверждения пользователем. Нерешённые вопросы источника и новые рабочие названия перечислены в отчётах соответствующих глав и сносках самого перевода.

Запускайте команды из этой папки; `python` можно заменить путём к локальному Python или conda.

```powershell
python database_tools.py verify
python database_tools.py progress
python database_tools.py search '"hit points"'
python database_tools.py search 'Природоведение'
python database_tools.py export
```

Для правки в Excel сделайте копию CSV соответствующей главы. Меняйте `russian`, `note` и при необходимости `status` (`draft`, `reviewed`, `user_approved`). Сохраните CSV UTF-8 с разделителем `;`. Не изменяйте идентификатор, английский текст, его SHA-256 и номер редакции.

```powershell
python database_tools.py import-chapter edited_01.csv --chapter 01 --reviewer Arsik
python database_tools.py verify
python database_tools.py export
```

Импорт проверяет главу, неизменность английского текста и ожидаемый номер редакции. Несовпадение отклоняет весь пакет. Изменения записываются одной транзакцией; прежние редакции сохраняются. Пустой русский текст не удаляет существующий перевод. Повторный импорт неизменённого файла ничего не меняет. Импорт с устаревшими номерами редакций отклоняется — после правки создавайте свежую выгрузку.

Для следующих глав подготовьте отдельный CSV или JSONL с теми же полями и `revision: 0` для новых переводов. Файл должен содержать только выбранную главу. Для главы 2 используется `--chapter 02`. Новые переводы и изменения помечают главу `in_progress`; завершение смысловой вычитки отмечается отдельно после проверки всей главы.

Не создавайте базу заново поверх существующей: это уничтожит историю. Для резервной копии закрытой базы достаточно скопировать SQLite-файл; при открытой базе используйте SQLite Backup API.
