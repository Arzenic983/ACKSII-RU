# Глоссарий ACKS II

Словарь проекта для переводчиков и редакторов. Сохранены исходные формулировки, варианты и нерешённые редакционные пометы. Вопросительный знак или комментарий в записи не означает утверждённого решения. Машинная версия словаря находится в `База перевода/glossary.json`; дополнительные утверждённые формы и правила применения описаны в README проекта.
