# Глава 7: перевод, проверка и сборка

PDF 316–333, 964 единицы. styled.json содержит оформленный русский текст, notes.json — редакторские примечания, figures.json — исходную схему с русской легендой. Исходный снимок: ../../contributions/07/source.jsonl. Утверждение человеком не присваивается.

Повторная сборка: python .work/ch07-md/fragment_tools.py из корня проекта. До интеграции проверяется исходная revision 0; после интеграции ожидаемые текущие редакции и русский текст сверяются с integration.json. Таблицы должны быть полными; геометрия проверяется независимым HTMLParser. После завершения сборки главы запускается python .work/reading-md/format_reading.py; при необходимости задать ACKS_NODE. Команды читают существующие переводы, не создают новый перевод.

integrate.py уже выполнен. Он сохраняет снимок SQLite Backup API, вызывает штатный import-chapter, verify и выборочный экспорт. Повторное выполнение блокируется существующим снимком. terminology_revision1.jsonl — однократное уточнение Clear → Равнины, уже импортированное как revision 2. Повторять импорт нельзя. Английские поля, геометрия и другие главы проверены на неизменность.

semantic_review.json описывает вычитку одним ИИ-редактором, visual_review.json — ограниченный просмотр исходных PDF 319, 320, 321, 333. Полная визуальная вычитка отсутствует. Изображение схемы находится в ACKSII/Перевод Markdown/assets/. Историческая копия сборщика читательского файла до расширения — format_reading_before.py; не запускать поверх нынешней сборки.

Финальная проверка после сборки и интеграции: `python .work/ch07-md/validate_final.py`. Она независимо разбирает отображаемый HTML, сравнивает все 964 текста с пакетом и SQLite, кости, проценты и знаки модификаторов с английским оригиналом, а остальные главы — с резервным снимком. Это не визуальная вычитка.
