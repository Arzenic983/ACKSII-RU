# Глава 12: воспроизведение и проверки

Revised Rulebook, PDF 474–487, 809 единиц: 43 заголовка, 164 абзаца, 14 пунктов, 588 ячеек 9 таблиц. Сохранено 21 редакторское примечание. Перевод и повторная смысловая сверка выполнены одним Codex; утверждение человеком и независимая вычитка другим агентом не назначались.

Основной английский источник — EN checked.md. Все 14 полных тел страниц точно совпадают с pages.source_markup базы. Исходные ID, английские единицы, SHA-256, геометрия таблиц и утверждённый словарь не менялись. Числовых исключений сопоставления нет. Английские разделители тысяч заменены русскими, а десятичные точки — запятыми. Числа, кости, проценты, знаки модификаторов, числовые пороги, операции, выделения и разрывы строк проверены.

Канонические русские тексты — translations.tsv, cell_terms.tsv и presentation_parts.json. assemble_texts.py запрещает пропуски, сохраняет числовые ячейки и записывает pure.json. labels.py применяет term_rules.tsv только к представлению. term_map.json — рабочая карта подписей; новые формы не считаются утверждёнными. notes.json хранит вопросы, styled_notes.json — их оформление.

На PDF 480 перемешаны две колонки и подписи схемы. source_parts.json соединяется точно в исходные английские единицы, presentation_parts.json хранит соответствующие русские части. presentation.py восстанавливает порядок по просмотренному изображению PDF. Все 30 единиц страницы отображены в 38 фрагментах, каждый ровно один раз; валидатор отдельно собирает их обратно по ID и индексу. Схема — четыре вложенных HTML-блока, без дополнительной таблицы или единиц. Полная глава сохраняет data-unit/data-part, а читательский сборщик удаляет служебные атрибуты.

Из корня проекта:

```sh
python .work/ch12-md/build_chapter.py
python .work/ch12-md/validate.py
python .work/reading-md/format_reading.py
python "ACKSII/База перевода/database_tools.py" verify
```

Для читательской сборки нужен Node.js с marked; ACKS_NODE задаёт путь к Node. Локальные пути bundled runtime в validate.py, preview.py и visual_check.mjs замените на другой машине. preview.py создаёт 11 локальных образцов, visual_check.mjs — снимки и метрики. Фактически просмотренные изображения перечислены в visual_review.json; создание снимка само по себе не считается вычиткой всей страницы. Просмотрены все 9 русских таблиц и отдельные восстановленные области PDF 480, но не вся проза 14 страниц визуально.

validate.py сверяет все 809 русских единиц после рендеринга marked, все сетки/объединения/пустые позиции таблиц, CSV/JSONL, исходные редакции, хеши, английские страницы, неизменяемые таблицы SQLite и все другие главы. baseline.json защищает прежние Markdown-файлы; сводку примечаний разрешено только дописать. Для переноса проверки восстановите прежний префикс сводки в editor_notes_before.tmp из коммита 8509643 и сверьте его хеш с baseline.json.

**Одноразовые операции не повторять поверх результата:** setup.py захватил исходную базовую точку и адаптировал прочитанные сборщики главы 11; seed_cells.py перенёс только точные совпадения ранее переведённых ячеек; prepare_labels.py согласовал начальные тексты и объединил правила. finalize_review.py лишь записал результат фактически выполненной смысловой вычитки и просмотра, не заменяет их. integrate.py создал резервную копию и выполнил официальный импорт revision 0→1. extend_reader.py адаптировал читательский сборщик и дополнил сводку примечаний; update_docs.py обновил навигацию.
