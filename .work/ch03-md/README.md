# Глава 3: сборка и проверка

Рабочие материалы перевода Revised Rulebook, PDF 102–123. Главные результаты находятся в `ACKSII/Перевод Markdown/`, пакет — в `contributions/03/`, отчёт — в `ACKSII/База перевода/03_review.md`.

- `source_units.json`, `source_tables.json` — неизменённый снимок исходных единиц и таблиц главы.
- `baseline.json` — контрольные суммы защищённых файлов, английских таблиц базы и прежних переводов до начала работы.
- `translated_*.md` — вручную переведённые абзацы с постоянными ID и английскими подписями.
- `auto_units.py` — словарные заголовки, списки навыков и числовые клетки; `table_cells.py` — явно переведённые остальные клетки.
- `notes.json`, `working_terms.json` — примечания и рабочие варианты терминов.
- `review_tools.py` — выравнивание по ID и сравнение числовых токенов; `compare_lists.py` — сравнение английских списков двух глав.
- `build_chapter.py` — полная двуязычная глава и пакет с исходной `revision: 0`; базу не меняет.
- `validate.py` — независимая от сборки проверка полноты, таблиц после разбора Markdown, чисел и защищённых данных.
- `update_support.py` — дополнение карты терминов и сводных примечаний.
- `integrate.py` — выполненный одноразовый этап интегратора: резервная копия, штатный импорт, проверка, экспорт. Не запускать повторно без проверки редакций.
- `polish.py` — зафиксированные исправления авторской вычитки; `prepare.py` — первоначальная подготовка снимков. Для повторной сборки они не нужны.

Из корня проекта, Python 3.10+ и Node.js 20+ с `marked`:

```sh
python .work/ch03-md/auto_units.py
python .work/ch03-md/table_cells.py
python .work/ch03-md/review_tools.py
python .work/ch03-md/build_chapter.py --reviewed
python .work/ch03-md/validate.py
python .work/reading-md/format_reading.py
```

`--reviewed` допустим после вычитки; без него пакет получает `draft`. Полные главы 1–2 не пересобираются. Итоговый общий файл содержит начало и главы 1–3; сборка доказывает сохранность прежнего читательского текста. Локальные изображения PDF, выровненные файлы для чтения и HTML-предпросмотр главы исключены из Git как воспроизводимые промежуточные материалы.

Содержательные изменения после импорта требуют свежей выгрузки с текущей `revision`. Исторический пакет с нулевой редакцией не повышайте вручную и не импортируйте повторно. При правке только оформления русский текст в базе не переписывается.
