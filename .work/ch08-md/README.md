# Воспроизведение главы 08

Канонические оформленные тексты — `styled.json`, примечания — `notes.json`. Диапазоны и отчёты — `parts/`; исходный экспорт неизменён в `../../contributions/08/source.jsonl`. `initial_fragment.json` сохраняет предыдущие 275 единиц; согласованные уточнения перечислены в `initial_fragment_corrections.json`.

1. `python build_chapter.py` собирает полную главу, CSV/JSONL и технический отчёт. База читается только для проверки. `fragment_tools.py` — совместимая точка входа в эту же сборку.
2. `python validate_final.py` сравнивает все отображённые единицы с пакетом и SQLite, проверяет механику и сохранность других глав. Node нужен для `../ch02-md/render_document.mjs`; путь к текущему bundled runtime указан в скрипте.
3. Общий файл собирается последним: `python ../reading-md/format_reading.py`; путь к Node можно задать через `ACKS_NODE`. `extend_reader.py` только настраивает этот сборщик на главы 1–8 и текущий счётчик сносок.

`integrate.py` уже выполнен: SQLite Backup API, штатный import-chapter и verify, сравнение остальных глав и неизменных исходников, выборочный экспорт. **Не повторяйте импорт исходной редакции 0** поверх нынешней редакции 1. Резервная копия `before_chapter08.sqlite.tmp` локальна и исключена из Git. Для последующей редакции сначала сделайте свежий export-chapter, проверьте актуальные revision и изменённые записи; не пересоздавайте базу.

`merge_parts.py` воспроизводит оформленные тексты из изолированных результатов и сохранённого первоначального фрагмента; после ручных правок styled.json не запускайте его без переноса правок в соответствующий подпакет. Авторские черновые скрипты и PDF-изображения частей не входят в поставку. `semantic_review.json`, `visual_review.json`, отчёты частей и независимые сверки описывают фактически выполненную проверку; пользовательское утверждение не присваивалось.
