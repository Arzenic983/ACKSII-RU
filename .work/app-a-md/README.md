# Приложение A: воспроизведение и проверки

Revised Rulebook, физические PDF 488–507, 344 единицы, две таблицы и 20 примечаний. Канонические русские тексты: `translations.tsv`, `table_rows.json`, `language_nodes.tsv`. Последний файл хранит вручную сверенную глубину 58 узлов и обе русские колонки языковой схемы; английские узлы должны соединяться точно в две исходные единицы.

```sh
python .work/app-a-md/build_chapter.py
python .work/app-a-md/validate.py
python .work/reading-md/format_reading.py
python "ACKSII/База перевода/database_tools.py" verify
```

Сборка читателя требует Node.js и marked; `ACKS_NODE` позволяет задать исполняемый файл. Локальные пути runtime в validate.py, preview.py, prepare_images.py и visual_check.mjs адаптируйте на другой машине. Для изображений требуются Poppler и Pillow. `prepare_images.py` только извлекает, обрезает поля и поворачивает исходные иллюстрации PDF; английские надписи карты не перерисовываются. Готовые два изображения сохранены в `ACKSII/Перевод Markdown/assets/`.

`build_chapter.py` читает SQLite без изменений, проверяет исходные хеши и редакции, создаёт полное приложение и два обменных пакета. `labels.py` добавляет только обратимые английские подписи. Имена в списках попарно сопоставляются с точными английскими написаниями; личные имена не подписывают обычные русские слова. Деревья и стихи имеют отдельное представление без новых единиц базы.

`validate.py` независимо разбирает рендеринг всех 344 единиц, две сетки таблиц, CSV/JSONL, неизменные английские страницы и таблицы базы, другие главы и прежние Markdown-файлы. `audit.py` проверяет числа, проценты, знаки, выделения и разрывы строк. `baseline.json` защищает исходное состояние. Для переноса проверки восстановите `editor_notes_before.tmp` из коммита a3026d7 и сверьте хеш: сводку примечаний разрешено только дописать. Все старые читательские файлы сохраняются.

`preview.py` и `visual_check.mjs` создают семь локальных образцов и снимки. Фактический просмотр описан в `visual_review.json`; создание снимка не равно визуальной вычитке. Проверены обе полные таблицы, карта, два дерева и стихотворение, но не вся проза визуально.

**Одноразовые операции не повторять:** `setup.py` создал исходный пакет revision 0 и базовую точку; `adapt_checks.py` подготовил проверки из прочитанных скриптов прежних глав; `integrate.py` создал резервную копию и импортировал 344 единицы официальным инструментом; `extend_reader.py` расширил сборщик и сводку примечаний. Последние операции защищены от повторного импорта. Резервная копия `before_appendixA.sqlite.tmp` игнорируется Git.

`semantic_review.json` фиксирует выполненную одним Codex смысловую сверку и хеш русского текста, без утверждения человеком. После изменения смыслового текста требуется новая сверка и пакет актуальных редакций. `contributions/A` сохраняет исходную revision 0; текущие SQLite и `A_review.csv` — revision 1.
