# Воспроизведение извлечения Revised Rulebook

Готовые файлы находятся в `ACKSII/Source/`: `ACKSII Revised Rulebook (EN checked).md` и `ACKSII Revised Rulebook — проверка извлечения.md`.

Использованы Python, pdfminer.six, pdfplumber и Poppler. Текст получен из собственных кодов символов PDF; таблицы восстановлены из геометрии линий. `manual_pages.py` содержит сверенные по изображениям надписи на обложках, карте, разделителях и бланках.

Для повторной сборки из сохранённого сжатого кэша:

```powershell
python .work/revised-rulebook-extraction/build_text.py
python .work/revised-rulebook-extraction/finalize.py
```

Эта сборка создаёт промежуточный `EN working text`, затем перезаписывает итоговый `EN checked` и отчёт. Редакторские изменения непосредственно в итоговом файле нужно сохранить перед повторной сборкой.

Для повторного извлечения из того же исходного PDF перед сборкой запустите `collect_corrected.py`. Он использует `font-codes.json` и `geometry.jsonl.gz`. `repair_font_encoding.py` восстанавливает таблицы соответствия кодов символов по именам глифов. `audit_pdf.py` выполняет первоначальную проверку геометрии; она нужна при замене исходного PDF.

Основные журналы:

- `final-validation.json` — итоговые проверки и SHA-256 исходного PDF и английского текста;
- `build-checks.json` — полнота каждой страницы, счётчики и диагностические флаги;
- `corrected-collection-checks.json` — сверка количества выводимых символов с первым проходом;
- `tables.json` — сетки таблиц и объединения ячеек;
- `final-excluded-glyph-audit.json` — контроль исключённых колонтитулов и боковых заголовков;
- `hyphen-joins.json` — сохранённые дефисы на переносах;
- `packaging-checks.json` — сверка сжатого кэша с исходным несжатым потоком.

`pages-corrected.jsonl.gz` содержит полный набор исправленных символов, их координат, шрифтов, цветов и таблиц. Несжатые промежуточные кэши удалены после проверки равенства SHA-256. Изображения для проверки можно повторно получить из исходного PDF через Poppler.
