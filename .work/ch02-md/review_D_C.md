# Независимая вычитка D по английским единицам

Проверены source_D.md и translated_D.md (PDF 82–101). Файл перевода D не изменялся.

## Замечания

1. **rr.p0089.b010 — deafened.** В переводе «Теневые чувства не действуют, если … оглушён». В исходнике `deafened`, то есть лишён слуха, а не оглушён в смысле stunned. Для точности состояния лучше «оглох» / «находится в состоянии глухоты». Это существенно, поскольку отсутствие слуха прямо выключает эхолокацию.
2. **rr.p0089.b008; rr.p0090.b006 — facing.** `cannot make a free facing change` передано «не может бесплатно изменить направление взгляда». Здесь речь об ориентации бойца в тактическом бою, а не только о направлении его взгляда. Лучше «не может бесплатно развернуться» или принятая в проекте формулировка изменения ориентации.
3. **rr.p0090.b007 — hijinks.** Передано «махинации», но глоссарий устанавливает «Происки». Это название игровой деятельности, поэтому следует заменить на «может заниматься Происками».
4. **rr.p0095.b015; rr.p0095.b021; rr.p0098.b007** (и **rr.p0096.b003** для противопоставления chaos/law) — в D космическое Law передаётся «Закон», тогда как в согласованном переводе C использован «Порядок». При общей сборке нужна одна форма. `unlawful` при этом остаётся «противозаконный» по смыслу обычного закона.
5. **rr.p0082.b010; rr.p0098.b011 — great axe.** Одно и то же оружие названо «большой топор» у мастера-жреца и «секира» у стража руин. Нужна единая форма названия оружия во всей главе.
6. **rr.p0083.b007; rr.p0095.b012 — magical constructs.** В D «магические конструкции», в C «магические конструкты». Упоминание големов в первом месте подтверждает, что это категория существ; желательно единообразное «магические конструкты».

## Редакционная унификация

- Название Argollë в D — «Арголле», в C — «Арголлэ»; выбрать одну форму: **rr.p0088.b006; rr.p0090.b013; rr.p0092.b006** и C rr.p0074.t02.r004.c02 / rr.p0078.b007 / rr.p0079.t03.r004.c02.
- B выполняет отдельную сверку названий заклинаний между диапазонами. Здесь дополнительно замечены разные переводы bane-rune («губительная руна» в D / «руна погибели» в C), beguile humanoid («очарование гуманоида» в D / «обольщение гуманоида» в C). Уточнить при общей сверке, не объявляя рабочие названия утверждёнными.
- В D сокращение «ст» без точки; в C по общему указанию использовано «ст.». При сборке можно унифицировать.

## Результаты проверки

- Все 474 единицы D присутствуют; пропусков и лишних ID нет.
- Числа и формулы соответствуют английскому. Различия автоматического сравнения чисел вызваны только русским разделителем тысяч (`15,000` → `15 000` и аналогично), потерь числовых значений не обнаружено.
- Проверены различия боевого развития, пределы рассечения, уровни заклинателей, особенности репертуара, бонусы спасбросков, длительность контроля, трата ячеек на Тайный удар/Исцеление смертью и условие запрета рассечения при убийстве сохранённым заклинанием. Существенных искажений этих правил не найдено.
- Огрехи исходника вроде ссылки Mage Templates (p. 35), повтора `st st`, расхождения plate/banded plate у крылатого рыцаря не следует исправлять без примечания рядом с соответствующим текстом.
