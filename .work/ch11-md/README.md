# Глава 11: воспроизведение и проверки

PDF 462–473, 618 единиц, 11 таблиц, 17 примечаний. Перевод интегрирован в SQLite и сшит в читательский файл глав 1–11. Перевод и повторная смысловая вычитка выполнены одним Codex; независимый технический разбор HTML — отдельным валидатором. Утверждение человеком не назначено.

Канонический русский текст — translations.tsv и cell_terms.tsv. assemble_texts.py объединяет словесные тексты и копирует числовые/костяные ячейки; пропуски запрещены. chapter_terms.tsv и существующие правила главы 10 объединены в term_rules.tsv; labels.py добавляет только подписи представления. Итоговые карты — styled.json, styled_notes.json и term_map.json. notes.json сохраняет редакторские вопросы.

Основной источник — EN checked.md. setup.py при подготовке точно сравнил тела всех 12 страниц с pages.source_markup; validate.py повторяет проверку. source_display_fixes.json документирует две поправки по изображению PDF 465: заголовок отображения и единственное числовое исправление пробела извлечения. Они не меняют английские единицы.

Из корня проекта:

```sh
python .work/ch11-md/build_chapter.py
python .work/ch11-md/validate.py
python .work/reading-md/format_reading.py
python "ACKSII/База перевода/database_tools.py" verify
```

Для читательского сборщика нужен Node.js и marked; ACKS_NODE задаёт путь к Node. validate.py/preview.py/visual_check.mjs используют пути bundled runtime этой машины; на другой машине замените их перед запуском. preview.py и visual_check.mjs создают только локальные образцы. Фактический охват просмотра — visual_review.json; наличие снимка не означает вычитки всей страницы.

Валидатор сопоставляет все русские единицы после рендеринга с пакетом, исходные поля/редакции, CSV/JSONL, таблицы и все исходные страницы, другие главы и неизменяемые таблицы базы. Прежние Markdown-файлы сверяются по baseline.json. Сводку примечаний разрешено только дописать: старый префикс проверяется по editor_notes_before.tmp. При переносе проверки на другую машину восстановите прежнюю сводку из коммита cbe6af7 и сверьте хеш baseline.json.

**Одноразовые операции не повторять поверх результата:** setup.py захватил исходный снимок и адаптировал прочитанные сборщики главы 10; prepare_labels.py согласовал ранний текст и собрал правила; integrate.py создал резервную копию и импортировал revision 0→1; extend_reader.py адаптировал читательскую сборку и дописал сводку; update_docs.py обновил навигацию. Это не команда повторного импорта. Для дальнейших смысловых правок сначала выгружайте актуальные редакции.

Резервная копия — before_chapter11.sqlite.tmp, не входит в Git. integration.json фиксирует официальный импорт 618 единиц и 28 115 переводов в базе. Все исходники, старые главы и утверждённый глоссарий сохранены. Новые термины рабочие.
