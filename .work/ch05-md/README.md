# Сборка и проверка главы 5

Глава завершена: PDF 180–263, 2 861 единица. Решения и границы проверки — в `../../ACKSII/База перевода/05_review.md`. `semantic_review.json` фиксирует завершение смысловой сверки; это проверка ИИ, не утверждение человеком. Полная визуальная проверка всех страниц не выполнялась.

Английские единицы и таблицы сохранены в `source_units.json` / `source_tables.json`. `baseline.json` содержит контрольные хеши источников и предыдущего перевода. `candidates.json` — первоначальные кандидаты из двух DOCX участников, которые перекрываются ручными файлами `translated_*.md` и `corrections_review_*.md`. Автоматическое выравнивание не является проверкой перевода.

Для воспроизведения текущего результата запускайте последовательно:

```powershell
python semantic_edits.py
python auto_units.py
python refine_terms.py
python annotate.py
python damage_labels.py
python check_spell_lists.py
python update_notes.py
python review_tools.py
python build_chapter.py --reviewed
python validate_draft.py --reviewed --integrated
```

`semantic_edits.py` восстанавливает `corrections_review_90.md` из явных исправлений. `auto_units.py` добавляет метаданные, заголовки и ячейки; `refine_terms.py` проверяет однозначные формы по словарю; `annotate.py` добавляет оформительские подписи; `damage_labels.py` восстанавливает формальные типы урона возле соответствующих костей. `review_tools.py` проверяет арабские числа, кости и формулы, но не заменяет чтение условий. `validate_draft.py` проверяет структуру, пакеты, исходники и сохранность предыдущих глав.

Исторические `prepare.py`, `read_drafts.py`, `align_drafts.py`, `catalog.py`, `assemble_candidates.py`, `common_corrections.py` и `minor_corrections.py` использовались для начальной подготовки. Не запускайте их поверх текущего результата без проверки: они могут перезаписать кандидаты, исходные контрольные данные или ручные исправления. `semantic_batches.json` сохраняет состав 34 прочитанных групп EN/RU; `semantic_edits.json` — журнал сверки и коротких правок.

`integrate.py` уже выполнен один раз. Он создаёт снимок, импортирует пакет официальным инструментом и выгружает прогресс. Повторный запуск блокируется существующим снимком и потребовал бы новых редакций. Не пересоздавайте SQLite и не объединяйте её бинарные версии.

Общий файл собирается отдельно: `../reading-md/format_reading.py`. Он доказывает сохранность предыдущих диапазонов хешами и сохраняет все примечания и таблицы. Локальные изображения PDF, HTML-просмотры и черновые выгрузки не включаются в коммит.
