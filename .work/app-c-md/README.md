# Приложение C: воспроизведение и проверки

Revised Rulebook, физические PDF 518–531, 827 единиц: 15 заголовков, 7 абзацев, 13 пунктов и 792 ячейки. Все 11 таблиц — 9×8. Сохранены 25 примечаний и пустая текстовая граница PDF 531. Вычитка выполнена одним Codex, без утверждения человеком.

```sh
python .work/app-c-md/build_chapter.py
python .work/app-c-md/validate.py
python .work/reading-md/format_reading.py
python "ACKSII/База перевода/database_tools.py" verify
```

Для сборки читателя нужны Node.js и marked; путь задаётся через ACKS_NODE. Локальные пути Node, Python и Edge в проверках адаптируйте для другой машины.

`translations.tsv` хранит 35 нетабличных единиц. `cell_terms.tsv` — ручные переводы по точному английскому ключу; `assemble_texts.py` распространяет только точные совпадения и сохраняет числовые ячейки. Сборка запрещает пропуски и неизвестные ID. `add_cells.py` — вспомогательный инструмент добавления вручную подготовленных пар ID/перевод, без генерации перевода и изменения базы.

`labels.py` применяет `term_rules.tsv` только к представлению; исходные `<br>` учитываются при поиске многословного термина. Notable и noticeable различаются по источнику. Mortally wounded не подписывается как название таблицы Mortal Wounds. Вставки обратимы; теги урона не становятся вложенными. `glossary_review.json` фиксирует проверенные словарные формы и рабочие названия.

`audit.py` проверяет числа, кости, проценты, знаки, пороги, операции, выделения и разрывы строк. Исключений нет. `validate.py` независимо разбирает весь HTML и сверяет 827 русских текстов с пакетом, сетки 11 таблиц, ID/хеши/редакции, CSV/JSONL и все 14 полных английских тел страниц. Защищены другие главы и неизменяемые таблицы базы. Прежние полные главы и читатели не изменены, сводка примечаний сохраняет старый префикс.

`preview.py` создаёт 14 образцов; `visual_check.mjs` проверяет геометрию и переполнение, создаёт 11 снимков таблиц и шесть фрагментов. `visual_reader.mjs` проверяет C в общем читателе при ширине текста 1080 px. Создание снимка не означает просмотра: фактически просмотренные изображения и ограничения перечислены в `visual_review.json`. В печатный PDF перевод не верстался.

**Одноразовые действия не повторять:** setup.py создал исходную выгрузку revision 0 и baseline; integrate.py сохранил резервную копию и выполнил официальный импорт; extend_reader.py расширил состав читателя и сводку примечаний. Для проверки переноса восстановите editor_notes_before.tmp из коммита 6f7f6b7 и сверьте хеш baseline. Резервная копия before_appendixC.sqlite.tmp локальная и игнорируется Git. Для последующих смысловых правок сначала выгрузите актуальные редакции и применяйте официальный импорт нового пакета.

assemble_partial.py, validate_partial.py и partial_*.json — историческая контрольная точка до импорта, созданная при паузе из-за лимита. Эти проверки требуют revision 0 и после интеграции намеренно не запускаются. Текущие проверки — validate.py и C_validation.json.
