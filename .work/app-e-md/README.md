Node.js с marked нужен для рендеринга; ACKS_NODE задаёт его путь. Локальные пути Node, Python и Edge в проверках адаптируйте для другой машины. Перед воспроизведением нужен Git LFS с настоящими SQLite/PDF.

parse_index.py извлекает записи из неизменённого source.jsonl. source_display_fixes.json содержит единственное числовое исключение: по изображению PDF 546 восстановлены полные ссылки трёх уровней магических исследований. Все исходные числа сохранены, изменился порядок после восстановления колонок. Английские единицы и хеши не менялись.

label_translations.tsv — проверенная карта 857 названий. match_labels.py подбирал кандидатов по уже переведённым главам; candidate_review.tsv был прочитан целиком, 35 явных уточнений сохранены в manual_labels.tsv. Это кандидаты и сверка, а не независимая человеческая вычитка. translations.tsv хранит 59 остальных единиц; имена спонсоров оставлены в исходном написании, без выдуманных границ и транслитераций. assemble_texts.py восстанавливает все 83 единицы.

build_chapter.py создаёт полный Markdown, CSV с BOM и `;`, JSONL исходной revision 0. Только в отображении rr.p0548.b004 перенесён перед обратным указателем, а rr.p0548.b002 и b005 объединены в один заголовок. Все ID сохранены. Для каждого номера страницы ссылка рассчитана по pages базы и ведёт к границе полного общего перевода. В SQLite английские оформительские подписи отсутствуют.

validate.py независимо разбирает HTML, сверяет русский текст всех 83 единиц с пакетом, 862 записи и 975 ссылок, 13 полных тел EN checked, имена, номера редакций и неизменность других глав/исходных таблиц базы. audit.py проверяет числа, знаки, выделения и разрывы строк. Отдельно проверены восстановленные списки и заголовок. semantic_review.json привязан к хешу русского набора; изменения смысла требуют новой вычитки.

preview.py и visual_check.mjs проверяют все 13 образцов на переполнение. visual_reader.mjs проверяет E внутри общего файла и переходы по ссылкам. Фактически просмотренные изображения перечислены в visual_review.json. Не заявляется визуальное чтение каждой записи и каждого имени на PDF; печатная PDF-вёрстка не создавалась.

**Не повторять одноразовые операции:** setup.py создал исходную выгрузку и baseline от коммита 53e77ae; prepare_texts.py зафиксировал проверенные названия; integrate.py сохранил SQLite через Backup API и выполнил официальный import-chapter, verify и export; extend_reader.py расширил сборщик и сводку примечаний. before_appendixE.sqlite.tmp и editor_notes_before.tmp — локальные резервные копии, игнорируемые Git. Для дальнейших правок выгружайте текущие редакции и импортируйте новый пакет.
