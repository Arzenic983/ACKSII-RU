# Глава 10: воспроизведение и проверки

PDF 448–461; 521 единица, 14 таблиц, 21 примечание. Результат интегрирован и сшит в читательский файл глав 1–10. Перевод и повторная смысловая вычитка — один Codex; независимая техническая проверка реализована отдельным разбором HTML, вторую смысловую вычитку другим агентом не заявляем.

Канонический русский текст — translations.tsv и cell_terms.tsv. assemble_texts.py объединяет их, копируя только явно числовые клетки, римские коды, 1D8 и числа с gp. Пропуски запрещены. term_rules.tsv/labels.py и notes.json задают только представление. styled.json, styled_notes.json и term_map.json — результаты сборки. Английские подписи не пишутся в SQLite.

Из корня проекта с Python 3.10+:

```sh
python .work/ch10-md/build_chapter.py
python .work/ch10-md/validate.py
python .work/reading-md/format_reading.py
python "ACKSII/База перевода/database_tools.py" verify
```

Для рендеринга нужен Node.js и установленный marked; ACKS_NODE задаёт путь Node читательскому сборщику. validate.py/preview.py/visual_check.mjs сохраняют путь к bundled runtime этой рабочей машины; на другой машине замените его перед запуском. preview.py и visual_check.mjs создают локальные образцы, не публикацию. Снимки и резервные копии игнорируются Git; фактический визуальный охват — visual_review.json.

validate.py сравнивает весь русский текст после marked с пакетом, таблицы с геометрией SQLite, тела всех 14 страниц EN checked.md с pages.source_markup, пакеты CSV/JSONL, исходные поля и редакции, неизменность других глав и исходных таблиц. Для сводки редакторских примечаний разрешено лишь дописывание с проверкой неизменного префикса по editor_notes_before.tmp. Для переноса проверки на другую машину без локальной копии прежней сводки восстановите её из исходного коммита 49513ff и проверьте хеш baseline.json.

**Одноразовые исторические операции не повторять:** prepare.py создал снимок исходного состояния; correct_review.py записал ранние уточнения; integrate.py выполнил резервное копирование и импорт revision 0→1; align_titles.py импортировал две отсылки revision 1→2; extend_reader.py адаптировал сборку и дописал примечания; update_docs.py обновил навигацию. Они не являются последовательной командой повторного импорта. Исходные пакеты устарели относительно нынешней SQLite.

Резервная копия — before_chapter10.sqlite.tmp. integration.json фиксирует две строки revision 2. semantic_review.json и corrections.json описывают смысловую сверку; 10_review.md — итоговый отчёт. Все прежние английские источники, утверждённый глоссарий и полные главы сохранены. Новые термины рабочие; user_approved не назначен.
