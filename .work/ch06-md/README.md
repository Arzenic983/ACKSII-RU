# Перевод и сборка главы 6

PDF 264–315, 2 144 единицы. Основные результаты и границы проверки — `../../ACKSII/База перевода/06_review.md` и `06_validation.json`. Вычитка Codex не означает утверждения человеком.

`prepare.py` читает SQLite и DOCX, сохраняет исходные единицы, таблицы и контрольные хеши. Он выполнен один раз; не запускайте его поверх текущего снимка. `align.py` создавал только непроверенные кандидаты: автоматическое выравнивание не является переводом или вычиткой. `review_01.py`–`review_18.py` содержат ручные переводы и исправления 671 текстовой единицы. `labels.py` содержит переводы заголовков и словесных ячеек, числовые значения сохраняются из источника. `final_edits.py` фиксирует последние смысловые и языковые исправления.

Текущий результат можно воспроизвести последовательно:

```powershell
python labels.py
python polish.py
python audit.py
python annotate.py
python build_chapter.py
python validate.py --integrated
python ../reading-md/format_reading.py
```

Нужны Python 3.10+, Node.js и закреплённый в проекте `marked`. В текущей среде использованы встроенные runtime Codex. Сборщик принимает `ACKS_NODE`, затем использует доступный встроенный Node или Node из `PATH`. Английские подписи добавляются только в Markdown. Проверки HTML подтверждают таблицы и позиции ячеек; они не заменяют визуальной вычитки.

`integrate.py` уже выполнен: снимок, официальный атомарный импорт, `verify`, экспорт. Повторный запуск блокируется существующим снимком и потребует актуальных редакций. Он не пересоздаёт базу. `extend_reader.py` — одноразовая адаптация просмотренного сборщика на главы 1–6; повторно запускать не нужно.

`write_reports.py` обновляет местные отчёты только после подтверждённой интеграции и проверки общего файла. `semantic_review.json` фиксирует авторскую сверку ИИ; независимого второго рецензента и полного постраничного визуального просмотра не было. Изображения PDF 270, 278, 303 просмотрены. Исходные PDF/DOCX не изменены.
