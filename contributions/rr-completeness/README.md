# Поправки итоговой сверки RR

18 октября 2026 года. Пакеты по главам 02, 03, 04, 05, 06 и 08 содержат десять записей: две правки русского текста и восемь дополнений примечаний. CSV — UTF-8 с BOM и разделителем `;`, JSONL — UTF-8. ID, английский текст, source_sha256 и исходная revision сохранены.

**Уже импортированы** через database_tools.py import-chapter. Повторно не импортировать: номера revision в этих пакетах описывают состояние до правки. Для дальнейшей работы выгружайте текущую главу из базы. Утверждение человеком не присваивалось.

Результаты и причины: [отчёт проверки](<../../ACKSII/База перевода/RR_проверка_полноты.md>). Точные исходные и итоговые редакции сохранены в истории SQLite.
