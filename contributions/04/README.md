# Глава 4. Снаряжение

<small>CHAPTER 4: EQUIPMENT</small>

Revised Rulebook, PDF 124–179. Переведены и вычитаны Codex все 4 566 единиц; утверждение человеком не присваивалось. Актуальная полная глава — `ACKSII/Перевод Markdown/04 Снаряжение.md`; отчёт — `ACKSII/База перевода/04_review.md`.

`translator.csv` (UTF-8 BOM, разделитель `;`) и `translator.jsonl` содержат одинаковые данные с **исходной revision 0**. Английские поля и SHA-256 сохранены; русский текст не содержит оформительских английских вставок Markdown. Импорт выполняется интегратором через `database_tools.py import-chapter`, с предварительным снимком базы. Повторно импортировать этот пакет после успешного импорта нельзя: получите свежую редакцию главы.

`corrections_01.csv/jsonl` — отдельный пакет семи терминологических исправлений с фактической редакцией 1. Он уже импортирован; соответствующие записи базы теперь имеют редакцию 2. Полный пакет редакции 0 также отражает окончательный русский текст и пригоден как полная передача результата, но не для повторного импорта поверх нынешней базы.

Рабочие переводы по ID, словарь таблиц, исходная контрольная точка и скрипты сборки/проверки находятся в `.work/ch04-md/`. `auto_units.py` собирает проверенные словарные и числовые ячейки; `build_chapter.py --reviewed` собирает полный Markdown и пакет, `review_tools.py` сверяет числа, `validate.py` — полноту, структуру и неизменность исходников. `integrate.py` выполняет однократный импорт; перед повторным запуском требуется проверить состояние базы и существующий снимок.
